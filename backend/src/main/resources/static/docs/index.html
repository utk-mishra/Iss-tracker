ISS Location & Pass Predictor API

This is a small, self-contained documentation page (no CDN, no external dependency). The full machine-readable contract is at /openapi.yaml. This page works fully offline - it is a static file served by the same app.

Endpoints

MethodPathDescription
GET/api/v1/iss/overview?lat=&lon=&offline=Position, passes, next visible pass, alerts, per-upstream meta
GET/api/v1/iss/position?offline=Current ISS position only (poll every 5-10s)
GET/api/v1/iss/passes?lat=&lon=&offline=Pass predictions for an observer location
GET/actuator/healthBasic liveness check

Query parameters

NameTypeRequiredNotes
latnumberoverview, passesMust be finite, in [-90, 90]
lonnumberoverview, passesMust be finite, in [-180, 180]
offlinestringnoMust be exactly "true" or "false" (default "false")

Example curl commands

curl "http://localhost:8080/api/v1/iss/overview?lat=28.6139&lon=77.2090"

curl "http://localhost:8080/api/v1/iss/overview?lat=28.6139&lon=77.2090&offline=true"

curl "http://localhost:8080/api/v1/iss/position"

curl "http://localhost:8080/api/v1/iss/passes?lat=28.6139&lon=77.2090"

curl -i "http://localhost:8080/api/v1/iss/overview?lat=91&lon=0"   # 400 example

Degradation levels

SourceMeaning
FRESHLive upstream data, or a cache entry still within its TTL
STALEExpired cache entry served because the upstream failed or is offline
MOCKStatic labelled fallback data; nothing usable was cached

Rate limiting

Requests to /api/** are limited per client IP (default 120/minute, configurable via RATE_LIMIT_PER_MINUTE). Exceeding the limit returns HTTP 429 with a Retry-After header.
